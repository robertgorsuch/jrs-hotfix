# jrs-hotfix 0.9.1

The menu takes you through a WAR's waiting merge, as it already did the server's. It closes the
one limitation the 0.8.0 and 0.9.0 notes listed for the menu, and changes nothing else. Download
the archive for your system below, check it against `SHA256SUMS`, and unpack it in place of the
old one. It includes its own Java; nothing needs to be installed. `README.md` inside the archive
is the manual; `jrs-hotfix --docs` prints it.

## What changed

- **The menu follows a WAR's waiting merge through** (#64). When entry 8's "Hotfix it into a new
  WAR" stops (exit 2) because files of its merge wait for your decision, the menu now does what
  entry 1 does on the server:
  1. it finds the merge prepared from exactly that package (by its SHA-256) in the **WAR's own
     home**, chosen as `apply --war` chooses it: `--home`, else `JRS_HOTFIX_HOME`, else
     `jrs-hotfix` beside the WAR;
  2. it lists the files and takes each in turn: show what changed, take the merged file, keep the
     site's, take the hotfix's, or install a file you merged yourself;
  3. it offers to hotfix the WAR again with that merge and the same options (`--generic`,
     `--install-out`, `--keep-superseded`).

  Enter stops and keeps the decisions made so far; entry 8's "Its merges" continues them. Before,
  the menu only pointed at "Its merges", and you ran the hotfix again yourself.

## What scripts must change

Nothing. No command, option, message or exit code changed; only the menu goes further.

## Tested

`verify` green in CI on Linux and Windows, the acceptance tests through the shaded jar among
them: 655 unit tests and 20 acceptance tests. New tests cover a WAR's merge decided in its own
home and the WAR hotfixed again with the same options, stopping part way, and, on a real
`apply --war` that waits, the merge found in the WAR's home and gone once resolved.

This release was tagged without live runs on a real server, as 0.9.0 was.

## Known limitations

- A WAR's home is offered the server's baselines only when it is the one beside the WAR; with
  `--home`, run `baseline import` yourself.
- The limitations of 0.8.0 stand, except the one this release removes.
